# Skills

Each folder is one skill: `SKILL.md` (what the agent reads first), its reference files in capitals, and `agents/openai.yaml` for Codex. They run in order for a new video, and each also works on its own.

- **[write-script](./write-script/SKILL.md)**: Research to a script ready to record: fact table, angle, hook options, a peak map, and a storyboard in your voice. The voice has two layers: [UNSLOP.md](./write-script/UNSLOP.md) (not sounding like AI) and [VOICE.md](./write-script/VOICE.md) (your persona, which learns from every line you change).
- **[hook](./hook/SKILL.md)**: The opening picture and title, built so frame 0 works as the thumbnail inside Instagram's grid crop.
- **[edit-video](./edit-video/SKILL.md)**: Raw clips in CapCut to a new draft: transcribe, fact-check, cut the gaps, grade, level the audio, place pictures and animation, and bilingual subtitles.
- **[find-pictures](./find-pictures/SKILL.md)**: The still picture for each point, from official sources or Wikimedia with licence, placed on the words it shows.
- **[animated-shots](./animated-shots/SKILL.md)**: Animation in Remotion, from single shots to whole videos, in a style picked fresh per video ([STYLES.md](./animated-shots/STYLES.md)): parallel builders, two judges with a mute test ([REVIEW.md](./animated-shots/REVIEW.md)), and cards and memes ([CARDS.md](./animated-shots/CARDS.md)).
