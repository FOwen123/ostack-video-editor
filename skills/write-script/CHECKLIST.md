# Script checklist

Every script passes these before the user sees it (step 6).

| Check | Passes when |
|---|---|
| **Speed to value** | The first 5 seconds give a reason to stay: the news, the stakes or the journey already moving. Dates, company intros and "In this video" come later or go. |
| **Contrast** | The script holds at least one clear "you'd think X, but actually Y", backed by the fact table. |
| **Peaks** | No stretch over 15 seconds (about 50 words) without a peak from the shape. |
| **Density** | Every line either carries a peak or explains one. A line the viewer could lose without missing anything is cut. |
| **Clarity** | Plain words, active voice. At most two new terms, each explained inline with "which basically means" or "meaning". |
| **Said twice** | The main point is said once short, then once simple with an example or comparison the user would pick (offer it; they cut analogies they didn't choose). |
| **Anticipation** | Something is teased before it's paid off, in the user's words ("And that's not even the scary part"). |
| **Emotion** | Words, visuals and sounds serve the one emotion from the angle. |
| **Rhythm** | Mostly short sentences, a medium or long one now and then. Many start with And, But or So. |
| **Voice** | Reads like the user's published scripts ([VOICE.md](VOICE.md)): their turns, their skepticism, their endings; the [UNSLOP.md](UNSLOP.md) pass is done. |
| **Facts** | Every claim matches its fact-table row; company-reported numbers are said as theirs. |
| **Length** | Word count ÷ 3.2 fits the shape's target. |
| **Ending** | Matches the shape: personal line and CTA, zoom-out callback, or callback to the opening. |
| **Visual change** | Every peak has an `On screen` change in the storyboard. |

For recording, not the script: energy up on the hook and the peaks. Re-record a line the user stumbled on.
